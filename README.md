# Redesign Website BNN Kota Banjarmasin

Project ini merupakan **study case remake website BNN Kota Banjarmasin** yang saya kerjakan untuk mengembangkan kemampuan dalam web development dan UI/UX design.

Pada project ini, saya mencoba membuat ulang tampilan website dengan desain yang lebih modern, rapi, dan nyaman digunakan. Selain memperbaiki tampilan, saya juga menambahkan beberapa fitur dan melakukan penyesuaian pada beberapa bagian website agar informasi dapat ditampilkan dengan lebih jelas dan mudah diakses.

Beberapa hal yang saya kerjakan dalam project ini meliputi:

* Membuat ulang tampilan website dengan desain yang lebih modern.
* Memperbaiki layout, warna, typography, dan beberapa elemen visual.
* Menambahkan beberapa fitur baru untuk meningkatkan fungsi website.
* Membuat tampilan yang responsive untuk berbagai ukuran layar.
* Menata kembali navigasi dan struktur halaman agar lebih mudah digunakan.
* Meningkatkan pengalaman pengguna melalui penerapan konsep UI/UX.

Project ini dibuat sebagai **study case dan project pembelajaran**, sekaligus menjadi bagian dari portofolio saya dalam mengembangkan website dan mendesain antarmuka.

> **Catatan:** Project ini bukan website resmi BNN Kota Banjarmasin. Project dibuat untuk keperluan pembelajaran, eksplorasi desain, dan pengembangan kemampuan web development.
